# Using this project

## Overview

This project is composed of two parts. In the first part, data on grants are retrieved from the SNSF Data Portal and AI-related grants are identified. Then, topic modelling is conducted on these AI-related grants, selecting the best model from a set of models with different numbers of topics. Finally, the top terms for each topic in the best model are passed to an LLM to help interpret the most recurrent topics among the AI-related grants. Here are the three scripts to run (in the order shown) to reproduce this first part of the project:

1.  `R/get_ai_related_grants.R`: fetching grant data and identifying AI-related grants.
2.  `R/topic_modelling.R`: performing topic modelling on the AI-related grant data and selecting the best model.
3.  `py/interpret_topics.py`: interpreting the topics identified by the best topic model.

In the second part, the results of the topic modelling analysis are rendered as a data story using Quarto (each language version has its own Quarto file: `en.qmd`, `de.qmd`, and `fr.qmd`). Note that rendering the Quarto files depends on the following R scripts:

-   `R/translations.R`: necessary for translating text in figures.
-   `R/helpers.R`: contains a helper function used to create interactive figures.
-   `R/tm_utils.R`: contains a utility function necessary to load the best topic model described in the data story.
-   `R/read_and_prepare_data.R`: contains the code for preparing the data used for the visualisations in the data story.
-   `R/make_figures.R`: contains the functions called in the Quarto files to create the visualisations in the data story.

To make the project reproducible, the outputs generated in the first part of the project are available in the `data` folder and are not regenerated by default. This behaviour is controlled by the parameters in the `params.yaml` file located at the root of this project. file located at the root of the project. The parameters contained in this file and their expected values are as follows:

-   `download_grants`: controls whether grant data should be downloaded from the SNSF Data Portal (`yes`) or a local copy should be loaded (`no -- default`).
-   `run_models`: controls whether topic models should be computed (`yes`) or local copies should be loaded (`no` -- default).
-   `eval_models`: controls whether topic models should be evaluated (`yes`) or existing model evaluation data should be loaded (`no -- default`).
-   `write_top_terms`: controls whether the top terms from the best topic model should be saved (`yes`) or a local copy should be loaded (`no` -- default).
-   `period_start`: specifies the start of the time period covered by the grant data (refers to `CallDecisionYear` in the [SNSF Data Portal glossary](https://data.snf.ch/about/glossary); set to `2011` in the original analysis).
-   `period_end`: specifies the end of the time period covered by the grant data (refers to `CallDecisionYear` in the [SNSF Data Portal glossary](https://data.snf.ch/about/glossary); set to `2025` in the original analysis).
-   `model_size_min`: specifies the number of topics in the smallest topic model computed (set to `5` in the original analysis).
-   `model_size_max`: specifies the number of topics in the largest topic model computed (set to `100` in the original analysis).
-   `model_size_step`: specifies the increment in the number of topics between consecutive models (set to `5` in the original analysis).

## Using the different scripts

The analysis presented in the data story linked above can be reproduced using the scripts available in the `R` and `py` folders, which contain the R and Python scripts used in this project, respectively. All scripts are commented and provide more detailed information regarding how to use them and they actually do.

### Getting the data

As described in the info box at the end of the data story, the data are based on all grants written in English submitted to SNSF Project Funding and Career schemes that were awarded between 2011 and 2025, with a start date no later than 30 June 2026. The data were last collected on 14 September 2026, using the script `R/get_ai_related_grants.R` and saved to `data/snsf_grants_PF_CAR_2011_2025_part1.csv`, `data/snsf_grants_PF_CAR_2011_2025_part2.csv`, and
`data/snsf_grants_PF_CAR_2011_2025_part3.csv` (in see the "Read & prepare data" section in the script).

### Identifying AI-related grants

The AI-related grants were identified using the method described in a previous data story (see [How much of SNSF-funded research is related to artificial intelligence?](https://data.snf.ch/stories/ai-related-grants-en)). The code to filter for AI-related grants is available in the "Filter AI-related grants" section of the `R/get_ai_related_grants.R` script, and the list of SNSF AI keywords is available in `data/snsf_ai_keywords.csv`.

### Topic modelling

After identifying the AI-related grants, we applied topic modelling to identify recurrent topics in the corpus of titles, scientific abstracts and keywords from these grants. The code to reproduce the topic modelling analysis is available in `R/topic_modelling.R` (see also `R/tm_utils.R` for a set of helper functions used for topic modelling).

The approach adopted was to build several topic models with different numbers of topics (from 5 to 100, in increments of 5) and to assess which model best represented the corpus using the following metrics (see the article [Selecting the Number and Labels of Topics in Topic Modeling: A Tutorial](
https://doi.org/10.1177/25152459231160105) for more details on these metrics):

-   Held-out likelihood
-   Exclusivity
-   Semantic coherence
-   Model residual

The model with the best overall values across these four metrics was the model with 25 topics. In this project, we provide the following outputs from the topic modelling:

-   The results of the evaluation of all models (see `models/evaluated_models_snsf_grants_ai_2011_2025_k_5_to_100.rds`)
-   The selected best model containing 25 topics (see `models/snsf_grants_ai_2011_2025_k_025.rds`)
-   The top 10 terms and their respective weights for each topic in the best model which contains 25 topics (see `data/top_terms_snsf_grants_ai_2011_2025_k_025.csv`)

### Interpreting the topics

The topics were interpreted by providing the 10 most important terms, along with their weights (see `data/top_terms_snsf_grants_ai_2011_2025_k_025.csv`), to an open-weight large language model (Qwen3-4B) via Ollama. The Python script used for this interpretation step can be found in `py/interpret_topics.py`, while the system and user prompts used to query the model are available in `py/sys_prompt.txt` and `py/user_prompt.txt`, respectively.

The raw results returned by Qwen3-4B are available in `data/top_terms_snsf_grants_ai_2011_2025_k_025_with_labels.csv`. The labels were then reviewed and validated by the authors of the data story and are available in `data/top_terms_snsf_grants_ai_2011_2025_k_025_with_labels_validated.csv`.

## Data description

## `ai_related_grants_2011_2025.csv`

This dataset contains the AI-related grants retrieved from the SNSF Data Portal. The variables are described below, based on their definitions in the SNSF Data Portal [Glossary](https://data.snf.ch/about/glossary), except for the last three.

-   `GrantNumber`: Unique identifier of the grant.
-   `CallDecisionYear`: The call decision year is the year in which decisions on most grants of a call are made. It normally means the year in which a grant was approved.
-   `Title`: The grant title.
-   `Abstract`: A scientific abstract of the grant.
-   `Keywords`: The top five keywords of the grant in the order entered by the responsible applicant.
-   `EffectiveGrantStartDate`: Date on which the grant starts, as defined in the release of funds notice. For approved projects, this is a planned date. When requesting the release of funds, the applicants can change the planned start date.
-   `FundingInstrumentLevel1`: Top-level funding scheme hierarchy.
-   `grant_text`: Concatenation of the title, abstract, and keywords.
-   `n_unique_ai_keywords`: The number of unique AI keywords identified in `grant_text`.
-   `unique_ai_keywords`: The unique AI keywords identified in `grant_text`.

## `figure_translations.csv`

This dataset contains all translations of the text elements appearing in the figures presented in the data story. The translations are required to render the data story in the available languages. Each row contains one text element from the corresponding figure. The variables are described below:

-   `Figure`: The figure number, based on its order of appearance in the data story.
-   `en`: The English text element (label, data annotation, axis title, etc.) appearing in a figure in the data story.
-   `de`: The German translation of the text element in `en`.
-   `fr`: The French translation of the text element in `en`.

## `snsf_ai_keywords.csv`

This dataset contains the list of SNSF keywords used to identify AI-related grants. This is the list described in the data story [How much of SNSF-funded research is related to artificial intelligence?](https://data.snf.ch/stories/ai-related-grants-en). The variables are described below:

-   `keyword`: An AI keyword.
-   `Ambiguous`: Whether the keyword is ambiguous (see the data story mentioned above for more details on ambiguous keywords).

## `snsf_grants_PF_CAR_2011_2025.csv`

This dataset contains SNSF Project Funding and Career grants decided between 2011 and 2025 and retrieved from the SNSF Data Portal. This dataset served as the basis for filtering the AI-related grants (see `ai_related_grants_2011_2025.csv`). The variables are described below, based on their definitions in the SNSF Data Portal [Glossary](https://data.snf.ch/about/glossary), except for the last one.

-   `GrantNumber`: Unique identifier of the grant.
-   `CallDecisionYear`: The call decision year is the year in which decisions on most grants of a call are made. It normally means the year in which a grant was approved.
-   `Title`: The grant title.
-   `Abstract`: A scientific abstract of the grant.
-   `Keywords`: The top five keywords of the grant in the order entered by the responsible applicant.
-   `EffectiveGrantStartDate`: Date on which the grant starts, as defined in the release of funds notice. For approved projects, this is a planned date. When requesting the release of funds, the applicants can change the planned start date.
-   `FundingInstrumentLevel1`: Top-level funding scheme hierarchy.
-   `grant_text`: Concatenation of the title, abstract, and keywords.

## `top_terms_snsf_grants_ai_2011_2025_k_025.csv`

This dataset contains the top 10 terms and their corresponding weights for each of the 25 topics in the selected model. The variables are described below:

-   `topic`: The topic, coded as a number from 1 to 25.
-   `term`: A term with its corresponding weight in parentheses.

## `top_terms_snsf_grants_ai_2011_2025_k_025_with_labels.csv`

This dataset contains the labels and descriptions of the 25 topics as suggested by Qwen3-4B. The variables are described below:

-   `topic`: The topic, coded as a number from 1 to 25.
-   `label`: The topic label suggested by Qwen.
-   `description`: The topic description suggested by Qwen.

## `top_terms_snsf_grants_ai_2011_2025_k_025_with_labels_validated.csv`

This dataset contains the labels and categories of the 25 topics as validated by the authors of the data story, based on their review of the suggestions made by Qwen. The variables are described below:

-   `topic`: The topic, coded as a number from 1 to 25.
-   `label`: A short label describing the topic.
-   `label_category`: The label of the category to which the topic belongs, based on the six categories defined by the authors.
